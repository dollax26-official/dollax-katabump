# پنل دلکس — نسخهٔ پایتون (FastAPI + SQLite)

پنل مدیریت VPN خودمیزبان برای **KataBump** و هر هاست پایتونی: داشبورد وب + API + ربات کنترل تلگرام، با موتور پروتکل **Xray-core**.

این بستهٔ کاملاً جدید است (فایل‌های تازه) — شامل پشتیبانی از **اینباند WireGuard** و ویرایشگرهای JSON خروجی‌ها (Outbounds) و مسیریابی (Routing) به سبک 3x-ui.

---

## امکانات

- **اینباندها**: VLESS، VMess، Trojan، Shadowsocks و **WireGuard** — با ترنسپورت‌های WS / gRPC / xhttp / HTTPUpgrade / TCP / RAW، امنیت TLS و **Reality** (تولید خودکار کلیدهای X25519 + لیسنرهای خام TCP).
- **کاربران**: حجم، انقضا (تقویمی)، محدودیت IP/اتصال، تعداد کانفیگ هر کاربر، ویرایش / ریست / غیرفعال‌سازی از پنل یا ربات.
- **اشتراک‌ها**: صفحهٔ گرافیکی برای هر اینباند (قالب‌های xui · aurora · pasarguard · xg)، خروجی base64 و خام، هدرهای `Subscription-Userinfo`، لینک توکن هر کاربر و ورودی خلاصهٔ `SUB INFO`.
- **نودها**: اینباندهای پنل‌های دیگر، حلقهٔ سلامت خودکار.
- **استخر هاست‌ها**: چرخش IP تمیز در لینک‌ها.
- **خروجی‌ها و مسیریابی**: ویرایشگرهای JSON به سبک 3x-ui با قالب‌های آماده، اعتبارسنجی و اعمال زنده (با ذخیره، هسته دوباره اجرا می‌شود).
- **ربات تلگرام**: کنترل دکمه‌ای (منوی مالک؛ کاربر عادی دقیقاً دو دکمهٔ «دریافت کانفیگ» و «پروفایل من»)، ساخت خودکار کانفیگ آزمایشی، ویرایش/حذف کامل کاربر، زبان جدا برای هر کاربر (فارسی/انگلیسی).
- **چند ادمینه**: فهرست دسترسی بخش‌ها/اینباندها برای هر ادمین، تنظیمات شخصی، گزارش فعالیت با IP ادمین.
- **ظاهر**: ۷ پوسته، حالت شیشه‌ای/ساده، فونت‌ها، پس‌زمینه‌های آماده، موسیقی شخصی هر ادمین.

## راه‌اندازی سریع (KataBump یا هر هاست پایتونی)

```bash
# ۱) نصب پیش‌نیازها
pip install -r requirements.txt

# ۲) تنظیم محیط (نمونه: .env.example)
export SECRET_KEY="change-me-please"     # برای امضای نشست‌ها لازم است
export PORT=8080                          # بعضی هاست‌ها خودشان تعیین می‌کنند
export DATA_DIR=./data                    # پایگاه‌داده و کانفیگ‌های تولیدشده

# ۳) اجرا
python main.py
```

سپس `http://localhost:8080` را باز کنید — حساب مالک در اولین اجرا ساخته می‌شود
(پیش‌فرض `dollax26` / `dollax26` — همین حالا عوضش کنید، پایین را ببینید).

تغییر رمز مالک:

```bash
python set_password.py newpassword
```

### متغیرهای محیطی

| متغیر | پیش‌فرض | کاربرد |
|---|---|---|
| `PORT` | `8080` | پورت HTTP (بیشتر هاست‌ها خودشان می‌دهند) |
| `SECRET_KEY` | تصادفی در هر اجرا | کلید امضای نشست — مقدار ثابت بدهید تا نشست‌ها بعد از ری‌استارت بمانند |
| `DATA_DIR` | `./data` | محل پایگاه‌داده و کانفیگ xray |
| `XRAY_MODE` | `auto` | `auto` از هستهٔ xray موجود استفاده می‌کند؛ `off` فقط پنل |
| `DOLLAX_SINGLE_PORT` | خاموش | اجرای دقیقاً یک لیسنر روی `$PORT` |

> به‌صورت پیش‌فرض برنامه روی `$PORT` **و** `:8080` گوش می‌دهد (تور اطمینان برای هاست‌هایی که پورت مقصد ثابت مسیریابی می‌کنند).

## اینباند WireGuard

در سازندهٔ اینباند، پروتکل **wireguard** را انتخاب کنید — کلیدها (خصوصی + عمومی) خودکار ساخته می‌شوند.
هسته روی یک پورت خام UDP/TCP گوش می‌دهد و کاربران کانفیگ استاندارد WireGuard می‌گیرند. نمونهٔ کانفیگ و توضیح گام‌به‌گام: [WIREGUARD.md](WIREGUARD.md).

## ربات تلگرام

۱. با @BotFather یک ربات بسازید و توکن را بردارید.
۲. در پنل → تنظیمات → ربات: **توکن** و **آیدی عددی مالک** را وارد کنید.
۳. دکمهٔ شروع (یا `/start` در تلگرام). برای هر پنل فقط یک پولر — ربات با فایل قفل، نسخهٔ دوم را ساکت نگه می‌دارد.

## ساختار پروژه

| فایل | نقش |
|---|---|
| `main.py` | اپ FastAPI، ورود، تنظیمات، نظارت بر Xray |
| `api_extras.py` | لایهٔ API: نودها، هاست‌ها، اشتراک‌ها، تنظیم ربات، ویرایشگرهای JSON |
| `db.py` | لایهٔ SQLite (WAL) + اسکیما/مهاجرت |
| `protocol.py` | سازندهٔ لینک/کانفیگ، ابزار کلید Reality و WireGuard |
| `xray_core.py` | تولید کانفیگ Xray + کنترل پروسه |
| `tg_bot.py` | ربات کنترل تلگرام |
| `pages.py` | صفحات HTML + قالب‌های اشتراک |
| `relay.py` | رلهٔ بومی WS (VLESS-WS / Trojan-WS) |
| `static/` | رابط پنل (app.js، app2.js، style.css، sub-templates/) |
| `set_password.py` | ابزار تغییر رمز مالک |

## نکات امنیتی

- پیش از عمومی‌کردن پنل، رمز پیش‌فرض مالک را عوض کنید.
- Reality به یک ورودی **TCP خام** نیاز دارد: از TCP proxy / پورت دوم استفاده کنید و در تنظیمات → Xray-core مقدار `reality_host` و `reality_public_port` را بدهید.
- فقط VLESS-WS و Trojan-WS به‌صورت بومی رله می‌شوند؛ بقیه از Xray-core استفاده می‌کنند (پل به `127.0.0.1:10000+i`).
